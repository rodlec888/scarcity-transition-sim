# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone taking part in the project's spaces on
GitHub: issues, pull requests, discussions and reviews.

In short: be respectful, address ideas and evidence rather than people, and settle
disagreements about models and results through argument and data.

## Reporting

This repository belongs to an individual GitHub account, which gives no private channel
to its maintainer for conduct reports. To report a comment, an issue or a user, use
GitHub's **Report abuse** option, in the **...** menu of the comment or on the user's
profile. These reports go to GitHub Support, who act under the
[GitHub Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines).
See [Reporting abuse or spam](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

Security vulnerabilities are not conduct matters: report them as described in
[SECURITY.md](SECURITY.md).

## Enforcement

The maintainer may edit, hide or delete comments, lock conversations, limit interactions
and block users who break this code of conduct, following the enforcement guidelines of
the Contributor Covenant.
